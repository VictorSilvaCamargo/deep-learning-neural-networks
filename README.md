## 📖 Visão Geral

Implementações de arquiteturas neurais em PyTorch e TensorFlow/Keras: Redes Neurais Convolucionais (CNNs), Multi-Layer Perceptrons (MLP) com GridSearch e fundamentação de arquiteturas Transformers.

Este repositório reúne projetos práticos desenvolvidos com foco em engenharia de dados e inteligência artificial, demonstrando desde fundamentos teóricos até implementações práticas com validação experimental e métricas salvas.

---

## 🌟 Destaques do Portfólio

### 🔹 [Redes Neurais Convolucionais (CNNs) para Classificação de Imagens](./01_redes_neurais_convolucionais_cnn.ipynb)
Construção de CNN com camadas de convolução 2D, pooling, dropout para regularização, otimizadores adaptativos e curvas de aprendizado (loss/acurácia).

- **Stack:** `TensorFlow` `Keras` `CNN` `Deep Learning`
- **Notebook:** [`01_redes_neurais_convolucionais_cnn.ipynb`](./01_redes_neurais_convolucionais_cnn.ipynb)

### 🔹 [Arquitetura e Implementação de Transformers](./02_arquitetura_transformers_deep_learning.ipynb)
Estudo e modelagem dos blocos fundamentais de Transformers (Self-Attention, Multi-Head Attention e Feed-Forward Networks) para tarefas sequenciais.

- **Stack:** `PyTorch` `TensorFlow` `Transformers` `Atenção`
- **Notebook:** [`02_arquitetura_transformers_deep_learning.ipynb`](./02_arquitetura_transformers_deep_learning.ipynb)

### 🔹 [Multi-Layer Perceptron (MLP) com Otimização T-Fold GridSearch](./03_multi_layer_perceptron_gridsearch.ipynb)
Treinamento de perceptrons multicamadas com ajuste fino de topologia de camadas ocultas, funções de ativação e taxas de aprendizado.

- **Stack:** `MLP` `Redes Neurais` `Scikit-Learn` `GridSearch`
- **Notebook:** [`03_multi_layer_perceptron_gridsearch.ipynb`](./03_multi_layer_perceptron_gridsearch.ipynb)

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/VictorSilvaCamargo/deep-learning-neural-networks.git
   cd deep-learning-neural-networks
   ```
2. **Crie e ative um ambiente virtual:**
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```
3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Inicie o Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
